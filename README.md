# A 股投研日报系统（改进版模板）

零第三方依赖的 A 股投研看板：按《每日A股投研日报模板（改进版）》重构，**结论先行、涨跌对称、质检前置、三层分级**，抓取全球市场、成交额、涨跌停、板块资金双向、期指基差、精选公告等，生成可视化 HTML 看板并推送精简简报到微信。

> **重要说明**：这是**客观数据监测工具**，不是自动交易程序，不构成投资建议。它不会也不应该代你操作账户或下单，所有决策权在你手里。系统只做数据抓取与统计，不预测涨跌方向、不给买卖建议。

## 设计原则（改进版模板）

1. **结论先行**：打开第一屏就知道今天是什么性质的行情（强/中性/弱/急跌）。
2. **先质检再出数**：数据有问题的模块标灰/标缺失，且不产生异动信号。
3. **涨跌对称**：涨停与跌停、领涨板块与领跌板块、资金流入与流出，篇幅一致。
4. **三层分级**：必看（第一屏）、选看、备查（默认折叠）。
5. **时点标注**：区分"今日收盘"与"T-1"，拿不到的历史值标"待补"，不编造。

## 覆盖维度

| 板块 | 内容 | 数据源 |
|---|---|---|
| 数据质检 | 涨停家数一致、价格量级、K线完整、北向口径、财务期次、时点统一 | 本地校验 |
| 一句话结论 | 强/中性/弱/急跌分档 + 成交额放量缩量 + 最大特征 | 本地汇总 |
| 市场温度 | 涨跌家数、涨停跌停、炸板率、连板高度、昨涨停表现、成交额、两融（今日/昨日/变化） | push2 / push2ex |
| 指数与风格 | 8 大指数点位涨跌成交额 + 大盘/小盘/成长风格对比 | 东财 push2 |
| 板块四表 | 行业/概念：涨幅前5、跌幅前5、资金净流入前5、资金净流出前5；背离⚠️；成交额<1亿不上榜 | 东财 push2 clist |
| 涨停与跌停 | 按行业聚合、连板梯队（≥4/3/2板）、跌停区分ST、明细只列重点 | push2ex 涨跌停池 |
| 全球与外部 | 美股/港股/日经（含联动标注）、商品汇率、期指基差、国债收益率（缺失标注） | push2 |
| 我的持仓与自选 | 相对大盘、距MA20、量比、主力净占比（ETF不显示）、今日事件、信号 | push2 / F10 |
| 公告与要闻 | 并购/回购/减持/业绩/监管精选（≤10条）+ 政策监管宏观消息 | 东财公告 / 快讯 |
| 明日关注 | 限售解禁（未来3天）+ 数据/会议/交割提示 | 东财数据中心 |
| 龙虎榜（选看） | 净买前5、净卖前5，同股上榜原因合并 | 东财数据中心 |
| 异动信号（选看） | 标的/触发条件/当前值/阈值；质检不通过不产生信号 | 本地计算 |
| 备查（折叠） | 北向成交（降为备查，仅成交额无方向）、口径与风险提示 | 东财数据中心 |

## 相对上一版的改进

- **补齐**：两市成交额（今日值 + 放量/缩量）、跌停池按行业聚合、炸板率、连板梯队、期指基差、解禁日历、精选公告、宏观政策消息。
- **删除**：北向成交额从主区降到备查（仅成交额无方向、量级存疑）；ETF 的"主力净占比"与空技术指标列；固定茅台个股深度面板改为"仅触发信号才展开"。
- **去噪**：财经要闻改为关键词精选（并购重组、大额回购、减持、监管等），剔除程序性公告与小额噪音；板块榜加 1 亿成交额门槛。
- **降级为缺失标注**：昨日成交额、昨日涨停股表现、10年国债收益率、宽基ETF份额变动、部分经济数据日历——公开接口拿不到，如实标"数据缺失/待补"，不编造。

## 双模式

| 模式 | 命令 | 侧重 | 看板文件 |
|---|---|---|---|
| 盘前 | `python main.py --mode pre` | 隔夜全球市场、商品汇率、今日关注 | `投研看板_YYYYMMDD_pre.html` |
| 盘后 | `python main.py --mode post` | 收盘复盘、市场温度、涨跌停、板块资金、精选公告 | `投研看板_YYYYMMDD_post.html` |

不带 `--mode` 时按当前时间自动判断（12 点前为 pre，否则 post）。

## 微信推送

看板生成后自动把**精简简报**推送到微信，结构与看板一致：一句话结论 → 市场温度 → 板块涨跌对称 → 涨跌停 → 期指基差 → 龙虎榜/自选/信号 → 精选公告与宏观 → 明日解禁。北向成交降为一句备查提示。

渠道在 `config.py` 的 `PUSH` 配置（当前：PushPlus，已启用）：

| 渠道 | channel 值 | 凭证获取 |
|---|---|---|
| PushPlus（当前使用） | `pushplus` | https://www.pushplus.plus/ ，需实名认证，token 填 `pushplus_token` |
| Server酱 | `serverchan` | https://sct.ftqq.com/ ，SendKey 填 `serverchan_key` |
| 企业微信群机器人 | `wecom` | 群设置→群机器人→Webhook 填 `wecom_webhook` |

试运行：`python pusher.py --pre` / `--post`（只打印不发送）；实发测试：`python pusher.py --send --pre`。

> 凭证属于敏感信息，请勿提交到公开仓库。

## 技术说明

- **数据源**：东方财富公开接口（push2 / push2his / push2ex / 数据中心 / F10 / 公告 / 快讯 / 研报），无需 API key。
- **零依赖**：仅 Python 标准库 + 系统自带 curl。本机实测 Python urllib 的 TLS 握手会被东方财富断开，故统一改用 curl 子进程。
- **降级处理**：单个接口失败不影响其他模块，对应区块标"数据缺失/待补"并注明原因，绝不编造数值。
- **红涨绿跌**：A 股惯例。
- **离线可看**：看板为纯 HTML/CSS/内联 SVG，无外部 JS 或 CDN 依赖。
- **口径提示**：涨停池价格字段为放大值，已按 /1000 还原为元并与龙虎榜交叉校验；北向资金改革后仅披露成交额；主力净占比口径以数据源为准；技术指标为历史统计，过往表现不预示未来收益。
